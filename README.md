# Planning API

A Spring Boot backend for an expense management dashboard. The project is under active development, with an Angular frontend planned.

## Overview

Planning API is the backend foundation for a personal finance dashboard. It is being developed to support organizing financial data and tracking spending.

## Tech Stack

- Java 27
- Spring Boot 4.1.2
- Spring Web MVC
- Spring Data JPA
- H2 Database
- Bean Validation
- Maven
- Lombok
- MapStruct

## Getting Started

### Prerequisites

- Java 27
- Git

### Run the application

Clone the repository:

```bash
git clone https://github.com/JotaV3/planning-api-java.git
cd planning-api-java
```

Start the application with the Maven Wrapper:

```bash
./mvnw spring-boot:run
```

On Windows, use:

```bat
mvnw.cmd spring-boot:run
```

## Run Tests

```bash
./mvnw test
```

On Windows:

```bat
mvnw.cmd test
```
